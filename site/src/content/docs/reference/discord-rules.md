## Known differences from Discord

interaction tokens never expire (Discord: 15 minutes); callback `flags` aren't filtered to the five allowed ones; command `version` changes on every PUT; registered commands lack `nsfw`, `contexts`, `integration_types` defaults; timed-out members keep all their permissions (Discord: only VIEW_CHANNEL and READ_MESSAGE_HISTORY); no `X-RateLimit-*` headers outside 429s; READY lacks `session_type`; RESUME ignores `seq`; identify doesn't check 4003/4005/4013; component replies get message type 20 (unchecked); a member's own channel permissions aren't checked when they post, react or press (only that they're in the server).

- Gateway `zlib-stream` and ETF. discord.js asks for zlib-stream when `zlib-sync` is installed. The kit fails the request and closes with 4000, but discord.js resumes on 4000, so the bot reconnects in a loop until the test times out; the unmodelled-request check at teardown names the cause.
