---
title: Every action
description: Each thing a test can make Discord or a member do, with what it returns.
---

| `Discord`                                                                        | Returns                                      | Notes                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createDiscord({ quietTimeMs? })`                                                | `Promise<Discord>`                           | One per test, on its own port; `quietTimeMs` (default 100) is how long the bot must be quiet before a click or pick                                                                                   |
| `guild(name)`                                                                    | `Guild<N>`                                   |                                                                                                                                                                                                       |
| `category(guild, name)`                                                          | `Category<N>`                                |                                                                                                                                                                                                       |
| `textChannel(guild, name, category?)`                                            | `TextChannel<N>`                             |                                                                                                                                                                                                       |
| `forum(guild, name, tags?)`                                                      | `Forum<N>`                                   | `tags` are the tag names its posts can carry                                                                                                                                                          |
| `voiceChannel(guild, name)`                                                      | `VoiceChannel<N>`                            | Members join it with `joinVoice`                                                                                                                                                                      |
| `stageChannel(guild, name)`                                                      | `StageChannel<N>`                            | A moderator makes it live with `startStage`                                                                                                                                                           |
| `announcementChannel(guild, name)`                                               | `TextChannel<N>`                             | Other channels can follow it, and the bot can crosspost its posts                                                                                                                                     |
| `role(guild, name)`                                                              | `Role<N>`                                    | A role with no permissions, to pick in a select                                                                                                                                                       |
| `member(guild, name, { nickname?, permissions?, invite?, inactiveDays?, bot? })` | `Member<N>`                                  | A new user who joined `guild`; `permissions` gives them a role; `invite` is the code they joined through; `inactiveDays` is how long since Discord saw them, for prune; `bot: true` makes another bot |
| `owner(guild)`                                                                   | `Member<N>`                                  | Has every permission                                                                                                                                                                                  |
| `start(client, { commands?, permissions?, appOwner? })`                          | `Promise<void>`                              | `permissions`: what the bot's invite grants, in every guild, built before or after `start`; `appOwner` is the application's owner                                                                     |
| `answerWith(method, path, response)`                                             | `() => void`                                 | Answers a route with `response`, e.g. `respond.serverError(503)`; call the result to end it                                                                                                           |
| `deny(channel, who, permission)`, `allow(channel, who, permission)`              | `void`                                       | A channel overwrite for a member, a role, `"bot"` or `"everyone"`                                                                                                                                     |
| `disconnect()`                                                                   | `void`                                       | Discord drops the bot long enough that its session expires                                                                                                                                            |
| `reconnect()`                                                                    | `Promise<void>`                              | The bot identifies again; events in between are lost. Takes up to 6.5 s                                                                                                                               |
| `autoArchive(thread)`                                                            | `void`                                       | Discord archives it for inactivity                                                                                                                                                                    |
| `skipTime(ms)`                                                                   | `Promise<void>`                              | Ends every collector whose `time` or `idle` runs out within `ms`; the bot's own `setTimeout` calls don't fire                                                                                         |
| `setCommandPermissions(guild, command, overrides)`                               | `void`                                       | An admin's overrides for `command`; `target` is a member, a channel or the guild (@everyone)                                                                                                          |
| `kickBot(guild)`                                                                 | `void`                                       | The bot gets `guildDelete` and hears nothing more from `guild`                                                                                                                                        |
| `startOutage(guild)`, `endOutage(guild)`                                         | `void`                                       | The bot gets `guildUnavailable`, hears nothing from `guild`, then `guildAvailable`                                                                                                                    |
| `messages(channel)`                                                              | `Message[]`                                  | Oldest first, live objects                                                                                                                                                                            |
| `dms(member)`                                                                    | `Message[]`                                  | The bot's DMs with `member`                                                                                                                                                                           |
| `waitForMessage(channel, text)`, `waitForDM(member, text)`                       | `Promise<Message>`                           | Waits for a match written since the latest action, up to 2 s                                                                                                                                          |
| `waitForThread(channel, name)`                                                   | `Promise<Thread>`                            | Waits for a thread the bot started there, up to 2 s                                                                                                                                                   |
| `waitForTextChannel(server, name)`                                               | `Promise<TextChannel>`                       | Waits for a text channel in the server whose name matches, such as one the bot created, up to 2 s                                                                                                     |
| `waitForThreadFrom(message)`                                                     | `Promise<Thread>`                            | The thread the bot starts from `message`, whatever it names it, up to 2 s                                                                                                                             |
| `waitForIdle()`                                                                  | `Promise<void>`                              | Resolves once the bot has gone quiet for 100ms                                                                                                                                                        |
| `waitForSound(channel)`                                                          | `Promise<void>`                              | Waits for the bot to play sound in a voice or stage channel, up to 2 s; says why when it doesn't                                                                                                      |
| `botVoiceChannel(guild)`                                                         | `VoiceChannel<N> \| StageChannel<N> \| null` | Where the bot is in voice                                                                                                                                                                             |
| `clientOptions`                                                                  | `{ rest: { api } }`                          | Spread into the bot's `Client` options                                                                                                                                                                |
| `token`                                                                          | `string`                                     | For a bot or deploy script that reads its own token; its first part is the application id in base64                                                                                                   |

| `Member`                                                                                 | Returns                          | Notes                                                                                                                      |

| `runUserCommand(channel, "Name", member)`, `runMessageCommand(channel, "Name", message)` | `Promise<Message>`               | A command from the Apps menu on a member or a message                                                                      |
| `typeInOption(channel, "cmd", option, typed, filled?)`                                   | `Promise<Choice[]>`              | The bot's suggestions while the member types into `option`                                                                 |
| `click(message, label)`                                                                  | `Promise<Message>`               | A button by its label, or its emoji when it has no label                                                                   |
| `select(message, label \| labels[])`                                                     | `Promise<Message>`               | A string-select option by its label; several labels for a multi-select                                                     |
| `select(message, pick \| picks[])`                                                       | `Promise<Message>`               | Members, roles or channels by handle, in the user, role, mentionable or channel select that offers them                    |
| `post(channel, message)`                                                                 | `Message`                        | Files are served by the mock                                                                                               |
| `postInForum(forum, post)`                                                               | `{ thread, message }`            |                                                                                                                            |
| `react(message, emoji)`                                                                  | `void`                           |                                                                                                                            |
| `unreact(message, emoji)`                                                                | `void`                           | Takes back their reaction; the bot hears `messageReactionRemove`                                                           |
| `vote(message, answer \| answers[])`, `unvote(message)`                                  | `void`                           | An answer by its text; several only when the poll allows it. The bot hears `messagePollVoteAdd` or `messagePollVoteRemove` |
| `startTyping(channel)`                                                                   | `void`                           | The bot hears `typingStart` with GuildMessageTyping                                                                        |
| `startStage(stage, topic)`, `endStage(stage)`                                            | `void`                           | Needs Manage Channels, Mute Members and Move Members; the bot hears `stageInstanceCreate`, `stageInstanceDelete`           |
| `closeDMs()`                                                                             | `void`                           | The bot's DMs to them fail with 50007                                                                                      |
| `setNickname(nick \| null)`                                                              | `void`                           | null goes back to their name                                                                                               |
| `setDisplayName(name \| null)`                                                           | `void`                           | Their global name; discord.js emits `userUpdate`                                                                           |
| `setPresence({ status, activity? })`                                                     | `void`                           | The bot hears `presenceUpdate` with GuildPresences; everyone starts offline                                                |
| `leaveGuild()`                                                                           | `void`                           |                                                                                                                            |
| `editMessage(message, text)`, `deleteMessage(message)`                                   | `void`                           | Their own message only, announced as MESSAGE_UPDATE / MESSAGE_DELETE                                                       |
| `kick(member, reason?)`, `ban(member, reason?)`                                          | `void`                           | Needs Kick or Ban Members and a higher role; logged in the audit log under them                                            |
| `renameGuild(name)`                                                                      | `void`                           | Needs Manage Server; the bot gets `guildUpdate`                                                                            |
| `lockThread(thread)`                                                                     | `void`                           | Needs Manage Threads; locks it without archiving                                                                           |
| `createInvite(channel, { maxUses? })`                                                    | `string`                         | The invite code; the bot hears `inviteCreate` with Manage Channels there                                                   |
| `joinVoice(channel)`, `leaveVoice()`                                                     | `void`                           | Joins a voice or stage channel. The bot gets `voiceStateUpdate`; joining needs Connect                                     |
| `createEvent(name, where, start)`, `editEvent(event, changes)`, `deleteEvent(event)`     | `ScheduledEvent<N>`, `void`      | `where` is a voice channel or a place; needs Create Events, or Manage Events for someone else's                            |
| `markInterested(event)`, `unmarkInterested(event)`                                       | `void`                           | The bot hears `guildScheduledEventUserAdd` or `guildScheduledEventUserRemove`                                              |
| `addEmoji(name)`, `addSticker(name)`, `renameExpression(e, name)`, `deleteExpression(e)` | `Emoji<N>`, `Sticker<N>`, `void` | Needs Create Expressions, or Manage Expressions for someone else's                                                         |

`label` is an exact string or a RegExp, and must match exactly one button or option. When the bot answers with a form (a modal), pass what the member types as the last argument of `runCommand`, `runUserCommand`, `runMessageCommand`, `click` or `select`, by field label: `alice.click(panel, "Report", { Reason: "spam" })`. The action then resolves with the bot's answer to the submitted form. `Message` is discord-api-types' `APIMessage`, and it's live: when the bot updates a message in place, the object the test holds shows it. `click` and `select` return the message visible afterwards, which is a new one only when the bot answers with a new message.

**Errors name what's there.** A failed action names messages by their text and lists what exists: `alice can't click "Cancel": "Pick a score" has buttons Confirm, 🔄, Rules`; `/reprot isn't registered. Registered: /report`.

**Types.** Handles carry their kind and guild: a category doesn't fit where a channel goes, and a `Member<"SIN">` can't act in another guild's channel or pass another guild's member as an option. Command names, labels and permissions are runtime checks: discord.js's builders type a command's name as `string`, so the literal never reaches the mock. The probes are in [`test/api.types.ts`](https://github.com/veksen-enterprises/discordjs-test-kit/blob/main/test/api.types.ts).
